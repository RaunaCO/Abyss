# Glossary

- **GPUI**: GPU-accelerated Rust UI framework (from Zed).
- **DASH / MPD**: segmented streaming + its manifest; used for Hi-Res.
- **SMTC**: Windows System Media Transport Controls.
- **WASAPI exclusive**: direct device access bypassing the mixer (bit-perfect).
- **ReplayGain**: per-track loudness normalization data.
- **LRCLIB**: open synced-lyrics provider.
- **Rail**: the narrow icon sidebar: [[UI System]].
