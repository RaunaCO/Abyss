# Project Overview

**Goal**: same UI and features as the official TIDAL desktop app, but native
(Rust + GPUI), faster, and with better audio quality.

**Principles**
1. Written from scratch; no forks of other clients.
2. Audio quality first: see [[Audio Pipeline]].
3. UI copied from the real app by screenshot comparison: see [[UI System]].
4. Leave room for obvious improvements: see [[Roadmap]].

**History**: started as an evaluation of tidalfast, became a from-scratch
build named `tidal-gpui`, rebranded to **TIDE**: see [[Brand Identity]] and
[[Decision Log]].
